# WhatsApp Clone (Flutter)

A modern, responsive WhatsApp Clone built with Flutter.

## Features Included:
- **WhatsApp Dark Theme & Colors**: Exact palette (teal/green accents, dark theme background).
- **Home Navigation**:
  - `CHATS`: List of recent chats, avatars, timestamps, and unread badges.
  - `STATUS`: My status, recent updates, viewed updates with circular status borders.
  - `CALLS`: Call logs with incoming/missed indicators, audio/video call buttons.
- **Chat Screen**:
  - Sent / Received message bubble cards with WhatsApp styling.
  - Message status (Double blue ticks ✔✔).
  - Bottom input bar with Emoji, Attachment bottom sheet, Camera, and Mic/Send toggle.
  - Call & Video call header buttons.

## How to Run:

1. Open this folder in VS Code:
   `C:\Users\DCK\.gemini\antigravity\scratch\whatsapp_clone`

2. Open the VS Code Terminal (`Ctrl + ~`) and generate the native platform files:
   ```bash
   flutter create .
   ```

3. Fetch packages:
   ```bash
   flutter pub get
   ```

4. Run the app:
   ```bash
   flutter run
   ```
